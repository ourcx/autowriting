## 支持的模型

### 1. 本地模式（Local Mode）

**特点**：
- ⚡ 快速生成，无需 API 密钥
- 🎨 生成 SVG 占位符封面
- 📱 适合快速预览和演示

**适用场景**：
- 快速测试功能
- 演示和原型设计
- 无网络连接时使用

**配置**：无需配置，开箱即用

### 2. Stability AI

**特点**：
- 🎨 高质量图片生成
- 🔧 支持多种风格和参数调整
- 💰 按使用量计费
- 🚀 生成速度快

**适用场景**：
- 生产环境使用
- 需要高质量图片
- 大批量生成

**获取 API Key**：
1. 访问 [Stability AI 官网](https://platform.stability.ai/)
2. 注册账户
3. 进入 [API Keys 页面](https://platform.stability.ai/account/keys)
4. 创建新的 API Key
5. 复制 API Key 到 `.env` 文件

**配置**：
```env
STABILITY_API_KEY=sk-your_api_key_here
STABILITY_BASE_URL=https://api.stability.ai/v1
STABILITY_ENGINE=stable-diffusion-3-large
```

**支持的引擎**：
- `stable-diffusion-3-large` - 最新的高质量模型（推荐）
- `stable-diffusion-3` - 标准模型
- `stable-diffusion-xl-1024-v1-0` - 快速生成

### 3. OpenAI DALL-E 3

**特点**：
- ✨ 最先进的图片生成模型
- 🎯 理解复杂的文本描述
- 🌟 生成质量最高
- 💎 按使用量计费

**适用场景**：
- 需要最高质量图片
- 复杂的创意需求
- 专业出版物

**获取 API Key**：
1. 访问 [OpenAI 官网](https://platform.openai.com/)
2. 注册或登录账户
3. 进入 [API Keys 页面](https://platform.openai.com/account/api-keys)
4. 创建新的 API Key
5. 复制 API Key 到 `.env` 文件

**配置**：
```env
OPENAI_API_KEY=sk-your_api_key_here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=dall-e-3
```

**注意**：
- DALL-E 3 需要付费账户
- 每个请求的成本约为 $0.08（1024x1024 分辨率）
- 生成时间约为 10-30 秒

## 配置指南

### 步骤 1：复制环境变量文件

```bash
cp .env.example .env
```

### 步骤 2：配置 Stability AI（推荐）

1. 获取 API Key（见上文）
2. 编辑 `.env` 文件：

```env
STABILITY_API_KEY=sk-your_actual_key_here
```

3. 重启服务器

### 步骤 3：配置 OpenAI（可选）

1. 获取 API Key（见上文）
2. 编辑 `.env` 文件：

```env
OPENAI_API_KEY=sk-your_actual_key_here
```

3. 重启服务器

### 步骤 4：验证配置

启动应用后，在「生成封面」页面可以看到：
- ✅ 已配置的模型会显示绿色勾号
- ❌ 未配置的模型会显示灰色

## 使用方法

### 在 UI 中选择模型

1. 打开「编辑文章」页面
2. 点击「生成封面」标签页
3. 在「选择 AI 模型」部分选择模型
4. 选择风格和颜色
5. 点击「生成封面」按钮

### 模型选择建议

**快速预览**：使用本地模式
```
- 快速查看效果
- 不消耗 API 配额
- 适合测试功能
```

**日常使用**：使用 Stability AI
```
- 生成质量高
- 成本合理
- 速度快
```

**高端应用**：使用 OpenAI DALL-E 3
```
- 最高质量
- 复杂描述理解能力强
- 适合专业出版
```

### 批量生成

在「批量生成」标签页中：
1. 选择要生成的风格和颜色组合
2. 选择 AI 模型
3. 点击「开始生成」
4. 系统会自动生成所有组合

## 故障排除

### 问题 1：API Key 无效

**症状**：生成时出现 "API Key 无效" 错误

**解决方案**：
1. 检查 `.env` 文件中的 API Key 是否正确
2. 确保 API Key 没有过期
3. 检查 API Key 是否有足够的配额
4. 重启服务器

### 问题 2：生成失败，自动降级到本地模式

**症状**：选择 Stability AI 或 OpenAI，但生成的是本地占位符

**解决方案**：
1. 检查网络连接
2. 检查 API Key 配置
3. 查看浏览器控制台的错误信息
4. 检查 API 服务是否正常运行

### 问题 3：生成速度很慢

**症状**：生成图片需要很长时间

**解决方案**：
- OpenAI DALL-E 3 生成速度较慢（10-30 秒），这是正常的
- 如果需要更快的速度，使用 Stability AI
- 检查网络连接质量

### 问题 4：生成的图片质量不好

**症状**：生成的图片与预期不符

**解决方案**：
1. 尝试修改文章标题，使其更具描述性
2. 尝试不同的风格和颜色组合
3. 使用 OpenAI DALL-E 3 获得更好的理解
4. 查看生成历史，对比不同模型的效果

## 成本估算

### Stability AI

- 按 API 调用次数计费
- 免费额度：每月 25 次调用
- 付费：约 $0.01-0.03 每次调用
- 月度成本（100 次调用）：约 $1-3

### OpenAI DALL-E 3

- 1024x1024 分辨率：$0.08 每次
- 1024x1792 或 1792x1024 分辨率：$0.12 每次
- 月度成本（100 次调用）：约 $8

## 最佳实践

1. **开发环境**：使用本地模式快速测试
2. **测试环境**：使用 Stability AI 验证效果
3. **生产环境**：根据需求选择 Stability AI 或 OpenAI
4. **成本控制**：
   - 使用缓存避免重复生成
   - 定期检查 API 使用情况
   - 设置使用配额告警
5. **质量保证**：
   - 测试不同的标题和描述
   - 对比不同模型的效果
   - 收集用户反馈
