## 📱 文档访问方式

### 在线访问
所有文档都在项目根目录，可以直接打开查看。

### 推荐工具
- **Markdown 编辑器**：VS Code、Typora、Obsidian
- **浏览器**：GitHub、GitLab、Gitee
- **命令行**：cat、less、more

### 快速访问命令
```bash
# 查看文档列表
ls -la *.md

# 查看特定文档
```
