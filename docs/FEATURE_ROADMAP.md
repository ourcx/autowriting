## 🎯 优化功能清单

### 第一阶段：AI 生成封面（框架）✅

#### 功能描述
- 根据文章标题和内容生成封面图
- 支持多种风格和尺寸
- 可调整和预览

#### 实现方案
```
选项 1: 调用在线 API（推荐）
├─ Stability AI (Stable Diffusion)
├─ OpenAI DALL-E
├─ 阿里云 AI 生成
└─ 百度 AI 生成

选项 2: 本地部署模型
├─ Stable Diffusion WebUI
├─ ComfyUI
└─ 需要 GPU 支持

选项 3: 框架先行
├─ 预留 API 接口
├─ 支持多个提供商
└─ 后续灵活切换
```

**推荐**：框架先行 + 调用在线 API

### 新增 API 端点

```
POST /api/articles/:dateDir/generate-cover
  - 生成封面图
  - 参数：标题、内容、风格
  - 返回：图片 URL

GET /api/articles/:dateDir/analyze
  - 分析文章内容
  - 返回：字数、关键词、建议等

POST /api/articles/:dateDir/optimize
  - 优化文章内容
  - 参数：优化类型
  - 返回：优化建议

GET /api/articles/:dateDir/seo
  - SEO 分析
  - 返回：SEO 评分和建议
```
