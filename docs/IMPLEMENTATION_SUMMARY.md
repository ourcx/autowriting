## 🔧 技术细节

### 内容分析算法

**关键词提取**：
```typescript
1. 分词：使用正则表达式分离中文和英文
2. 过滤：移除停用词（的、一、是、等）
3. 计数：统计词频
4. 排序：按频率降序排列
5. 截取：返回前 10 个关键词
```

**SEO 评分**：
```typescript
基础分：100
- 标题长度检查：±10 分
- 关键词数量检查：±10 分
- 内容长度检查：±10 分
- 关键词密度检查：±10 分
- 标题关键词检查：±5 分
- 段落结构检查：±10 分
```

**AI 套话检测**：
```typescript
检测 18 个常见 AI 套话：
- "在当今这个快速发展的时代"
- "随着科技的不断进步"
- "总而言之"
- "综上所述"
- ... 等
```

### 封面生成

**本地 SVG 模式**：
```javascript
1. 选择风格对应的 SVG 图案
2. 应用选定的颜色
3. 添加文章标题和日期
4. 转换为 Base64 Data URL
5. 返回给前端显示
```

**API 框架**：
```javascript
支持三种提供商：
- local：本地 SVG 生成（已实现）
- stability：Stability AI（框架预留）
- openai：OpenAI DALL-E（框架预留）
```

## 🚀 使用指南

### 快速开始

```bash
# 1. 安装依赖
cd web
npm install

# 2. 启动开发服务器
npm run dev

# 3. 在另一个终端启动后端
npm run server

# 4. 打开浏览器
# http://localhost:5173
```

### 功能使用流程

```
1. 编辑文章内容
   ↓
2. 点击「📊 内容分析」查看分析结果
   ↓
3. 根据建议优化文章
   ↓
4. 点击「🖼️ 生成封面」创建封面
   ↓
5. 选择风格和颜色，点击生成
   ↓
6. 预览并下载封面
   ↓
7. 点击「发布」发送到微信
```

## 🐛 已知限制

### 功能限制
1. **关键词提取**：使用简单分词，不支持复杂语义
2. **SEO 评分**：只检查基本指标，不包括链接和图片
3. **封面生成**：本地模式只生成 SVG，不支持真实 AI 图片
4. **分析速度**：大文本（>10000 字）可能有延迟
