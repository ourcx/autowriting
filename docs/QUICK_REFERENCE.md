# 🚀 快速参考指南

## 启动应用

```bash
cd web
npm install  # 首次运行
npm start
```

访问：http://localhost:5173

---

## 工作流

### 1️⃣ 创建文章
- 选择日期
- 点击「创建文章」

### 2️⃣ 编辑任务
- 点击「📋 任务要求」
- 填写文章主题、字数、结构等
- 点击「保存」

### 3️⃣ 整理素材
- 点击「📚 素材整理」
- 收集数据、案例、观点
- 点击「保存」

### 4️⃣ 生成文章
- 点击「⚡ 生成文章」
- 等待 30-60 秒
- 自动切换到「📝 文章内容」

### 5️⃣ 编辑和预览
- 点击「👁️ 预览」查看效果
- 或点击「✏️ 在线编辑」进行高级编辑
- 点击「保存」保存修改

### 6️⃣ 发布到微信
- 点击「发布」按钮
- 自动打开微信公众号平台
- 按照提示发布

## 常见问题

### Q: 编辑按钮没反应？
A: 已修复。请确保使用最新版本的应用。

### Q: 如何使用在线编辑器？
A: 点击「✏️ 在线编辑」标签，在 WeChat Markdown 编辑器中编辑，完成后复制内容粘贴到「文章内容」标签。

### Q: 如何发布到微信？
A: 点击「发布」按钮，自动打开微信公众号平台，按照提示发布。

### Q: 文章保存在哪里？
A: 保存在 `公众号写作/drafts/[日期]/` 目录中。

### Q: 如何删除文章？
A: 在仪表板找到文章，点击「删除」按钮。

## 故障排除

### 应用无法启动
```bash
# 清除缓存
rm -rf node_modules
npm install
npm start
```

### 后端无法连接
```bash
# 检查后端状态
curl http://localhost:3000/health

# 重启后端
npm run server
```

### 文件保存失败
```bash
# 检查目录权限
ls -la 公众号写作/drafts/

# 创建目录
mkdir -p 公众号写作/drafts
```
