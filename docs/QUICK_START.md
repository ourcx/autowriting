# ⚡ 快速开始指南

## 🚀 5 分钟快速启动

2. 填写任务要求和素材
3. 点击「生成文章」
4. 查看分析和生成封面

## 🔧 常见问题速解

### Q1：分析面板不显示？
**A**：确保文章内容不为空，刷新页面

### Q2：生成封面失败？
**A**：检查标题是否为空，查看浏览器控制台错误

### Q3：关键词不准确？
**A**：这是当前算法的限制，后续会改进

### Q4：SEO 评分很低？
**A**：检查标题长度、关键词数量、内容长度

### Q5：如何下载封面？
**A**：点击「⬇️ 下载」按钮，浏览器会自动下载

## 💡 使用技巧

### 技巧 1：快速生成高质量文章
1. 详细填写任务要求
2. 收集充分的素材
3. 使用 AI 生成初稿
4. 根据分析建议优化

### 技巧 2：优化 SEO 评分
1. 标题控制在 10-60 字
2. 添加 3-5 个关键词
3. 内容至少 500 字
4. 关键词密度 1-3%

### 技巧 3：选择合适的封面风格
- 科技文章 → 现代风格 + 冰沙蓝
- 教程文章 → 插画风格 + 抹茶绿
- 观点文章 → 极简风格 + 紫薯紫
- 案例分享 → 摄影风格 + 石榴红

### 技巧 4：避免 AI 套话
检查优化建议中的 AI 套话提示，手动修改以下表达：
- ❌ "在当今这个快速发展的时代" → ✅ "最近"
- ❌ "总而言之" → ✅ "总结一下"
- ❌ "极大地提升" → ✅ "提升了 30%"
