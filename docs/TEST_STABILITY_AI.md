# 🧪 Stability AI 集成测试指南

## 快速测试

### 第 1 步：启动应用

```bash
cd web
npm install
npm run dev      # 终端 1
npm run server   # 终端 2
```

### 第 2 步：打开应用

```
浏览器访问：http://localhost:5173
```

### 第 3 步：创建测试文章

1. 点击「新建文章」
2. 填写以下内容：

**任务要求**：
```
# 写作任务要求

## 基本信息
- **文章主题**：AI 写作工具实战指南
- **目标字数**：1500-2000 字
- **发布平台**：微信公众号

## 结构要求
1. 开场：直接切入痛点
2. 这是什么：解释 AI 写作工具
3. 怎么做：分步骤说明
4. 踩过的坑：分享真实问题
5. 值不值得做：给出明确判断
```

**素材整理**：
```
# 素材整理

## 核心数据
- AI 写作工具可以节省 70% 的时间
- 目前市场上有 50+ 个 AI 写作工具
- 用户满意度达到 85%

## 工具列表
- ChatGPT：通用 AI 助手
- Claude：长文本处理
- 自动写作系统：专业内容生成

## 踩过的坑
### 坑1：过度依赖 AI
- **问题**：完全依赖 AI 生成，不进行人工审核
- **原因**：想快速完成任务
- **解决**：建立审核流程，确保内容质量

## 个人观点
- AI 是工具，不是替代品
- 需要人工审核和优化
- 结合 AI 和人工可以达到最佳效果
```

### 第 4 步：生成文章

1. 点击「生成文章」按钮
2. 等待 AI 生成（约 30 秒）
3. 查看生成的文章

### 第 5 步：分析内容

1. 点击「📊 内容分析」标签页
2. 查看分析结果：
   - 字数统计
   - 关键词分析
   - SEO 评分
   - 优化建议

### 第 6 步：生成封面

1. 点击「🖼️ 生成封面」标签页
2. **选择 API 提供商**：选择「Stability AI（已配置）✅」
3. 选择设计风格：「🎨 现代风格」
4. 选择主色调：「🔵 冰沙蓝」
5. 点击「✨ 生成封面」按钮
6. **等待生成**（通常 10-30 秒）
7. 查看预览
8. 点击「⬇️ 下载」下载图片

## 常见问题

### Q1：生成超时怎么办？
**A**：检查网络连接，重试生成。如果持续失败，系统会自动降级到本地模式。

### Q2：生成的图片质量不好？
**A**：尝试不同的风格和颜色组合，或优化文章标题。

### Q3：如何查看生成日志？
**A**：打开浏览器开发者工具（F12），查看 Console 标签。

### Q4：如何报告问题？
**A**：记录问题详情，包括浏览器、操作步骤、错误信息，提交 Issue。
