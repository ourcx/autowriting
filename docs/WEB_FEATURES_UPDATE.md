```

  ↓
编辑器页面
```

```
  ↓
粘贴内容
  ↓
保存到草稿箱

预览和发布
```

## 📋 功能详解

### 编辑按钮
- **位置**：仪表板的文章卡片中
- **功能**：打开文章编辑页面
- **快捷键**：无
- **支持**：编辑已有的任何文章

### 在线编辑器
- **位置**：编辑器页面的「✏️ 在线编辑」标签
- **功能**：使用 WeChat Markdown 编辑器进行高级编辑
- **特点**：
  - 实时预览
  - 支持 Markdown 语法
  - 支持微信特有格式
  - 可复制编辑结果

### 发布按钮
- **位置**：编辑器页面的右上角
- **功能**：打开微信公众号平台
- **快捷键**：无
- **目标**：https://mp.weixin.qq.com/

## 🚀 快速开始

### 编辑已有文章

1. 打开仪表板
2. 找到要编辑的文章
3. 点击「编辑」按钮
4. 修改内容
5. 点击「保存」

### 使用在线编辑器

1. 打开编辑器页面
2. 点击「✏️ 在线编辑」标签
3. 在 WeChat Markdown 编辑器中编辑
4. 复制编辑结果
5. 粘贴到「📝 文章内容」标签

### 发布到微信

1. 编辑完成后
2. 点击「发布」按钮
3. 自动打开微信公众号平台
4. 按照提示发布文章

---

## 💡 使用建议

### 最佳实践

1. **使用在线编辑器**
   - 对于复杂的格式编辑
   - 需要实时预览的情况
   - 想要使用微信特有格式

2. **直接编辑文本**
   - 简单的内容修改
   - 快速编辑
   - 批量处理

3. **发布前检查**
   - 预览文章格式
   - 检查链接和图片
   - 确认没有敏感词
