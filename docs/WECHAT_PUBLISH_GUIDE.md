## 功能概述

微信发布功能提供了两种方式将文章发布到微信公众号：

### 自动发布（推荐）

- 🚀 一键发布到草稿箱
- 📱 自动打开微信编辑器
- ✅ 自动格式化文章内容
- 💾 保存为草稿，随时编辑

### 手动发布

- 📋 按步骤手动复制和粘贴
- 🎯 更灵活的控制
- 📝 适合需要调整的场景

## 发布方式

### 访问发布功能

1. 打开「编辑文章」页面
2. 点击「📱 发布」标签页
3. 选择发布方式

## 自动发布

### 步骤

1. **选择自动发布模式**
   - 在发布方式选择器中选择「🚀 自动发布」

2. **查看文章预览**
   - 确认文章标题、内容和封面
   - 显示文章字数和预计阅读时间

3. **点击发布按钮**
   - 点击「🚀 发布到草稿箱」按钮
   - 系统开始生成草稿

4. **等待完成**
   - 显示「正在生成草稿...」
   - 发布成功后自动打开微信编辑器

### 自动发布的优势

- ⚡ **快速**：一键发布，无需手动复制粘贴
- 🎨 **格式化**：自动转换为微信公众号格式
- 📱 **便捷**：自动打开微信编辑器
- 💾 **安全**：保存为草稿，可随时编辑

### 自动格式化规则

系统会自动将 Markdown 格式转换为微信公众号格式：

| Markdown | 微信格式 |
|----------|--------|
| `# 标题` | `<h1>标题</h1>` |
| `## 副标题` | `<h2>副标题</h2>` |
| `**加粗**` | `<strong>加粗</strong>` |
| `*斜体*` | `<em>斜体</em>` |
| `` `代码` `` | `<code>代码</code>` |
| ` ```代码块``` ` | `<pre><code>代码块</code></pre>` |
| `- 列表项` | `<li>列表项</li>` |

## 手动发布

### 步骤

1. **选择手动发布模式**
   - 在发布方式选择器中选择「📋 手动发布」

2. **复制文章内容**
   - 点击「复制」按钮
   - 文章内容已自动格式化并复制到剪贴板

3. **打开微信编辑器**
   - 点击「打开」按钮
   - 微信公众号平台会在新标签页打开

4. **粘贴内容**
   - 在微信编辑器中粘贴内容（Ctrl+V 或 Cmd+V）
   - 内容会自动保留格式

5. **上传封面**
   - 点击「上传图片」按钮
   - 选择文章封面图片

6. **保存为草稿**
   - 点击「保存」按钮
   - 文章保存为草稿

### 手动发布的优势

- 🎯 **灵活**：可以在每一步进行调整
- 📝 **可控**：完全掌控发布过程
- 🔧 **自定义**：可以修改格式和样式

## 发布历史

### 查看发布历史

发布页面底部显示「📜 发布历史」，记录所有发布的文章。

### 发布历史包含

- 文章标题
- 发布时间
- 发布状态（草稿/已发布）
- 文件路径

## 常见问题

### Q1：发布后文章在哪里？

A：发布后文章保存为微信公众号的草稿。你可以：
1. 在微信公众号后台的「素材管理」中找到
2. 继续编辑和调整
3. 选择发布时间后发布

### Q2：自动发布失败怎么办？

A：如果自动发布失败，可以：
1. 检查网络连接
2. 确保文章标题和内容完整
3. 尝试使用手动发布方式
4. 查看浏览器控制台的错误信息

### Q3：发布的文章可以编辑吗？

A：可以。发布的文章保存为草稿，你可以：
1. 在微信公众号后台打开草稿
2. 进行任何编辑和调整
3. 重新保存或发布

### Q4：如何修改已发布的文章？

A：在微信公众号后台的「素材管理」中：
1. 找到要修改的文章
2. 点击「编辑」
3. 进行修改
4. 点击「保存」或「发布」

### Q5：发布时可以添加「阅读原文」链接吗？

A：可以。在微信编辑器中：
1. 点击「阅读原文」按钮
2. 输入链接地址
3. 保存

### Q6：发布的文章格式不对怎么办？

A：可以在微信编辑器中调整：
1. 选择需要调整的文本
2. 使用编辑器的格式工具调整
3. 保存修改

### Q7：如何批量发布多篇文章？

A：目前需要逐篇发布。建议：
1. 先生成所有文章
2. 逐篇发布到草稿箱
3. 在微信后台统一管理

### Q8：发布历史可以删除吗？

A：可以。在发布历史中：
1. 找到要删除的记录
2. 点击删除按钮
3. 确认删除
