# 前端公共方法说明

## utils/apiHelpers.ts

前端 API 请求的公共工具函数，统一封装请求逻辑，避免各组件重复定义。

### 错误处理

```ts
extractErrorMessage(err: unknown, fallback?: string): string
```

从 axios/fetch 错误中提取可读的错误信息。优先读取 `err.response.data.error`，再读 `err.message`，最后返回 fallback。

### Key 配置检测

```ts
isLocalApiKeyConfigured(cfg: AIConfig): boolean
isLocalCoverKeyConfigured(cfg: AIConfig): boolean
```

判断用户本地配置中是否已填写 API Key。MaaS 检测 `maasApiKey`，其他检测 `articleApiKey`。

> 注意：这只检查本地配置。综合判断（含服务端）请用 store 的 `articleReady` 派生值。

### 文章操作

```ts
fetchArticle(articleId: string)
// 返回 { task, materials, article, title }

saveArticle(articleId: string, data: { task?, materials?, article?, title? })

generateArticle(articleId, task, materials, aiConfig): Promise<string>
// 返回生成的文章内容字符串

fetchArticleList()
// 返回 Article[] 列表

deleteArticle(articleId: string)
```

### 连通性测试

```ts
testAIConnection(cfg: AIConfig): Promise<{ ok: boolean; msg: string }>
```

向 `/chat/completions` 发 `max_tokens=1` 的最小请求，验证 Key 和 endpoint 是否可用。兼容所有 OpenAI 格式服务商（Claude、DeepSeek、Gemini 等）。

## utils/aiConfig.ts

localStorage 底层 CRUD，key：`wx-ai-config-v1`。

```ts
loadAIConfig(): AIConfig          // 读取配置（不存在时返回 DEFAULT_CONFIG）
saveAIConfig(config: AIConfig)    // 保存配置，同时触发 'ai-config-updated' 自定义事件
getEffectiveArticleConfig(config) // 根据 provider 返回实际请求用的 headers/url/model
```

常量：
- `PROVIDER_PRESETS` — 三种文章生成服务商预设（openai / openai-compat / maas）
- `COVER_PROVIDER_PRESETS` — 三种封面服务商预设（local / openai / stability）
- `DEFAULT_CONFIG` — 默认配置值

## store/useConfigStore.ts

全局 AI 配置状态，基于 `useSyncExternalStore`。

### Hooks

```ts
useConfigStore(): ConfigState
// 完整 store state，包括 localConfig、serverStatus、serverStatusLoading

useAIReadiness(): {
  localConfig: AIConfig
  serverStatus: ServerConfigStatus | null
  serverStatusLoading: boolean
  articleReady: boolean   // 本地 OR 服务端，任意一个可用
  coverReady: boolean
}
```

### 操作函数

```ts
setLocalConfig(cfg: AIConfig)           // 整体替换本地配置
updateLocalConfig(patch: Partial<AIConfig>)  // 局部更新
fetchServerStatus()                     // 拉取 /api/config/status，更新 serverStatus
```

### ServerConfigStatus 接口

从 `/api/config/status` 返回，只包含「是否已配置」，**不含 Key 明文**：

```ts
interface ServerConfigStatus {
  articleProvider: 'maas' | 'openai' | 'openai-compat' | null
  articleReady: boolean    // 服务端有可用的文章生成 Key
  maasReady: boolean
  maasEmail: string | null // MaaS 配置的邮箱（脱敏展示用）
  openaiReady: boolean
  coverProvider: 'local' | 'openai' | 'stability'
  coverReady: boolean
  dalleReady: boolean
  stabilityReady: boolean
}
```

## utils/templateStore.ts

CSS 样式模板管理，localStorage key：`wx-style-templates-v1`。

提供 5 套内置模板，支持用户自定义。被 StyleEditor 和 WeChatRenderer 使用。

```ts
loadTemplates(): Template[]
saveTemplates(templates: Template[])
getTemplate(id: string): Template | null
```
