# 系统架构说明

## 整体结构

```
autowriting/
├── web/                    # 前端 + 后端（同一个 npm 项目）
│   ├── src/                # React 前端源码
│   │   ├── store/          # 全局状态管理
│   │   ├── utils/          # 工具函数
│   │   ├── pages/          # 页面组件
│   │   └── components/     # 通用组件
│   └── server.js           # Express 后端
├── 公众号写作/drafts/        # 文章草稿（Markdown 文件）
├── .cache/                 # 封面缓存、图片库、生成历史
├── AGENTS.md               # 写作规范（注入 AI 提示词）
└── .env                    # 本地环境变量（不提交 Git）
```

## 前端路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | DashboardPage | 文章列表，创建/删除文章 |
| `/editor/:id` | ArticleEditor | 写作任务、素材、文章编辑、封面生成 |
| `/preview/:id` | WeChatPreview | 公众号样式预览，支持富文本复制 |
| `/styles` | StyleEditor | CSS 样式模板管理 |
| `/settings` | AISettings | AI Provider 和 API Key 配置 |

## 状态管理

### useConfigStore（`src/store/useConfigStore.ts`）

统一管理 AI 配置状态，基于 `useSyncExternalStore`，无需 Zustand。

```
ConfigState
├── localConfig: AIConfig     ← 用户在浏览器本地存储的配置
├── serverStatus              ← 从 /api/config/status 拉取的服务端状态
└── serverStatusLoading       ← 加载中标志
```

**派生值计算规则：**
- `articleReady` = 本地有 Key **OR** 服务端已配置 → 决定是否显示「未配置」横幅
- `coverReady` = 本地封面 Key 存在 OR 服务端封面就绪 OR 使用本地 SVG 模式

**更新方式：**
- `setLocalConfig(cfg)` — 整体替换，同步到 localStorage
- `updateLocalConfig(patch)` — 局部更新
- `fetchServerStatus()` — 拉取服务端配置状态（只含 `是否已配置`，不返回 Key 明文）

### aiConfig（`src/utils/aiConfig.ts`）

底层 localStorage CRUD，存储 key：`wx-ai-config-v1`。

## 配置优先级

```
用户浏览器本地配置（最高）
        ↓ 覆盖
服务端环境变量 SERVER_AI_CONFIG（.env 中配置）
```

前端生成文章时，将 `localConfig` 整体传给后端 `aiConfig` 字段；后端合并 `{ ...SERVER_AI_CONFIG, ...aiConfig }`。

## 文章文件结构

每篇文章对应 `公众号写作/drafts/` 下的一个目录：

```
drafts/
└── YYYYMMDD-文章标题/
    ├── prompt/
    │   ├── task.md        # 写作任务要求
    │   └── materials.md   # 素材整理
    ├── raw/
    │   └── article_raw.md # AI 生成的原始文章
    └── title.txt          # 文章标题（可选）
```

## 关键接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/articles` | 获取文章列表 |
| GET | `/api/articles/:id` | 获取单篇文章内容 |
| POST | `/api/articles/:id` | 保存文章 |
| POST | `/api/articles/:id/generate` | AI 生成文章 |
| DELETE | `/api/articles/:id` | 删除文章 |
| POST | `/api/generate-cover` | 生成封面图片 |
| GET | `/api/config/status` | 查询服务端配置状态（不含 Key 明文） |
| GET | `/health` | 健康检查 |
