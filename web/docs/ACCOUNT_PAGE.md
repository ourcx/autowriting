# 用户页

`/account` 是内容账号的统一入口，集中处理微信公众号、今日头条与小红书的绑定和数据展示。

## 账号绑定

- 微信公众号：填写 AppID 和 AppSecret，验证通过后显示账号基础信息和关注人数。
- 今日头条：粘贴已登录 `mp.toutiao.com` 后台导出的 Cookie JSON。系统验证 Cookie 后，显示创作中心首页仪表盘的粉丝数、总阅读(播放)量，以及收益总览页的累计收益数据。
- 小红书：粘贴已登录小红书创作服务平台导出的 Cookie JSON，用于文章发布预览中的小红书长文同步与发布。

两类凭据都只保存于当前浏览器的 `localStorage`，不会写入服务器数据库。解绑将删除本地保存的凭据。

## 数据刷新

- 公众号数据调用微信官方接口，需要账号具备相应权限；权限不足时会显示受限说明。
- 今日头条数据由服务端使用 Cookie 访问创作中心首页和收益总览页并提取页面可见指标。账号数据在服务端缓存 15 分钟；点击“刷新数据”会绕过缓存立即更新。头条后台页面改版或 Cookie 失效时，需要重新绑定。
- 小红书长文复用公众号正文，只维护独立标题；不会额外生成一篇小红书正文。

## 相关接口

- `GET /api/wechat/account`：读取公众号账号信息，需要 `X-Wx-AppId` 与 `X-Wx-AppSecret` 请求头。
- `POST /api/toutiao/account`：读取今日头条创作中心数据，需要登录态和 Cookie JSON。
