# 文章生成 Agent

在文章的「生成候选稿」里运行。每篇候选稿有自己的调研记录，公众号和头条可以并行生成。选用候选稿时沿用现有确认流程。

1. 从写作任务和素材提取主题。读取当前账号的写作画像、日常表达和已确认的改稿取舍，从知识库找旧文片段。
2. Agent 根据素材和已有网页结果选择搜索、阅读来源或结束调研。每篇候选最多四轮决策、两次搜索、两次读网页。来源列表里的 ID 由服务端分配，模型不能随意指定抓取地址。
3. 汇总实际读到的事实和尚待确认的范围，拟提纲。成稿只带当前任务、相关素材、简短写法例子和已读来源，搜索摘要只作为检索线索。
4. 候选稿页面显示当前步骤、历史参考数量和可打开的网页来源。中断发生在正文阶段时，续写复用已保存的写作准备，不重新付费搜索。

旧文章以该账号当前已保存的正文为准。向量索引存在时使用混合排序，刚保存的文章同时可用关键词找到。自动选取的旧文片段只示范句子节奏、段落展开与结构，作者明确确认过的画像和表达优先。旧文不用另行导入或手选，也不会自动变成永久文风规则。

网页工具使用 AI 配置中的 DeepSeek、智谱、Serper 或 SearXNG 搜索。DeepSeek 复用服务端配置，SearXNG 使用服务端地址或现有公共实例。默认 Serper 未配置 Key 时尝试 SearXNG。搜索或阅读失败时可继续使用已有素材。如果手工素材和母稿都为空，且没有读到公开正文，候选稿提示补充信息。已有调用方未选择文章 Agent 时沿用原有契约。

写法规则参考内部「好好说话」与 Writing DNA 资料，并结合公开的中文改写项目。系统提示中的三组短例子使用虚构素材，历史作者例子在每次生成时按账号读取。Agent 的工具结果回传、下一轮决策和预算上限参考 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/core.md)。
