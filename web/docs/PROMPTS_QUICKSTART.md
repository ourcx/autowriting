# 提示词可视化 - 快速开始

## 5 分钟快速上手

### 1. 访问提示词页面

在主导航栏点击「提示词」按钮，或直接访问 `http://localhost:3000/prompts`

### 2. 浏览内置提示词

系统预置了 9 个内置提示词，涵盖：
- 文章生成
- 文章分析
- 内联编辑（4 种）
- 大纲生成
- 素材整理
- 样式生成
- 封面生成

点击左侧列表中的任何提示词，右侧会显示详细内容。

### 3. 创建自定义提示词

点击「新建」按钮：

```
1. 填写名称：例如「我的自定义提示词」
2. 选择分类：从下拉菜单选择
3. 添加描述：简短说明用途（可选）
4. 编写内容：在文本框中输入提示词
5. 点击「保存」
```

### 4. 编辑提示词

选中一个提示词，点击「编辑」按钮：

```
1. 修改内容
2. 右侧实时显示预览
3. 添加变更说明（可选）
4. 点击「保存」
```

修改会自动创建新版本，历史版本保存在数据库中。

### 5. 查看版本历史

选中一个提示词，点击「版本历史」按钮：

```
- 显示所有历史版本
- 每个版本显示修改时间和说明
- 点击「恢复此版本」回到任何历史版本
```

## 常见操作

### 搜索提示词

在左侧搜索框输入关键词，支持按名称和描述搜索。

### 按分类过滤

点击分类标签过滤提示词：
- all：显示所有
- article：文章生成
- analysis：文章分析
- edit：内联编辑
- outline：大纲生成
- materials：素材整理
- style：样式生成
- cover：封面生成

### 复制提示词

选中提示词后，点击「复制」按钮，内容会复制到剪贴板。

### 删除提示词

选中自定义提示词，点击「删除」按钮。

**注意**：内置提示词不能删除。

## 提示词分类说明

### 文章生成 (article)
用于生成完整的文章内容。

**使用场景**：
- 根据任务要求和素材生成文章
- 结合 AGENTS.md 规范确保质量

**示例**：
```
你是一个专业的内容创作者。根据以下要求和素材，创作一篇高质量的文章...
```

### 文章分析 (analysis)
分析文章质量，检查是否符合规范。

**使用场景**：
- 评估文章质量
- 检查是否符合写作规范
- 识别需要改进的地方

**输出**：JSON 格式的分析结果

### 内联编辑 (edit)
在编辑器中对选中文本进行快速编辑。

**四种操作**：
1. **润色**：去掉 AI 感、套话、被动句
2. **精简**：精简到 60% 以内
3. **扩展**：补充案例和数据
4. **重写开头**：直接切入主题

### 大纲生成 (outline)
根据写作任务生成文章大纲。

**使用场景**：
- 规划文章结构
- 确保逻辑清晰
- 快速生成框架

**输出**：Markdown 格式的大纲

### 素材整理 (materials)
将原始素材结构化。

**使用场景**：
- 整理采集的素材
- 提取关键信息
- 为写作做准备

**输出**：结构化的素材总结

### 样式生成 (style)
生成微信兼容的 CSS 样式。

**使用场景**：
- 为文章生成自定义样式
- 确保微信渲染兼容性

**约束**：
- 不支持 CSS 变量
- 不支持 Grid 和 Flexbox gap
- 不支持渐变和动画

### 封面生成 (cover)
生成文章封面的图像提示词。

**使用场景**：
- 为文章生成配图
- 指导图像生成模型

**规格**：2.35:1 宽屏比例

## 最佳实践

### 编写清晰的提示词

✅ 好的例子：
```
请根据以下要求生成一篇文章：
1. 主题：AI 工具评测
2. 字数：2000 字
3. 风格：真诚、实用、人性化
4. 结构：开头、3 个工具评测、总结
```

❌ 不好的例子：
```
生成一篇文章
```

### 添加变更说明

修改提示词时，添加清晰的变更说明：

```
修改前：「在当今这个快速发展的时代...」
修改后：「我最近发现...」
变更说明：去掉空洞开场，直接切入主题
```

### 定期审查

定期审查提示词的使用效果：
- 查看使用次数
- 检查生成结果质量
- 根据反馈优化

### 版本管理

- 重要修改前查看版本历史
- 如果修改效果不好，快速恢复
- 保留有用的历史版本作为参考

## 统计信息解读

### 顶部统计栏

- **总提示词**：库中的提示词总数
- **内置**：系统预置的提示词数
- **自定义**：用户创建的提示词数
- **总使用次数**：所有提示词的累计使用次数

### 提示词详情中的统计

- **版本**：当前版本号
- **使用次数**：该提示词被使用的次数
- **创建时间**：提示词创建的时间
- **更新时间**：最后一次修改的时间

## 故障排除

### 提示词不显示

**问题**：左侧列表为空或提示词不显示

**解决**：
1. 刷新页面
2. 检查网络连接
3. 打开浏览器开发者工具，查看控制台错误

### 修改后没有保存

**问题**：修改提示词后，刷新页面内容没有保存

**解决**：
1. 确保点击了「保存」按钮
2. 检查是否有错误提示
3. 查看版本历史确认是否已保存

### 版本恢复失败

**问题**：点击「恢复此版本」后没有反应

**解决**：
1. 确保提示词不是内置的
2. 检查网络连接
3. 尝试刷新页面后重试

### 内置提示词不能编辑

**问题**：内置提示词的编辑按钮是灰色的

**说明**：这是正常的。内置提示词不能直接修改，但可以：
1. 创建新的自定义提示词
2. 复制内置提示词的内容作为参考
