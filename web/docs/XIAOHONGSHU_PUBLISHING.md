# 小红书图文发布

## 当前能力

- 在“用户页”绑定小红书创作服务平台的 Cookie JSON。
- 在每篇文章的“发布预览”页切换到“小红书长文”，直接同步当前文章标题与正文。
- 在预览页选择小红书长文模板、封面类型与封面信息展示项；可让 AI 生成下一步需要的发布标题、摘要和话题，确认后再一键同步并发布。
- 服务端以 Playwright 打开小红书统一发布页，再显式切换“写长文”入口并操作后续发布页。
- 每次请求写入 SQLite 发布记录，保留发布时间、图片数量、状态、结果链接或失败原因。

## 凭据与数据边界

- Cookie 仅保存在当前浏览器的 `localStorage`，不会写入 SQLite、日志或项目文件。
- 发布接口只在当前请求内把 Cookie 注入 Playwright 浏览器上下文，任务结束即关闭上下文。
- 图片先上传到项目既有的本地素材目录；发布记录只保存图片数量，不保存 Cookie。

## 操作方式

1. 在浏览器登录 `https://creator.xiaohongshu.com`。
2. 用 Cookie-Editor 等浏览器工具导出当前站点的 Cookie JSON。
3. 打开“用户页”，在“小红书”卡片粘贴并绑定 Cookie。
4. 打开任意文章的“发布预览”，切换到 **小红书长文**。
5. 当前文章的标题与正文会自动同步；可填写封面摘要，并选择模板、封面类型和封面信息。
6. 点击“AI 生成发布信息”，生成并允许编辑最终发布标题、封面摘要和 3–5 个话题。
7. 点击“一键发布长文”。系统先填标题和正文，点击“一键排版”，再选择模板、封面和展示项。点击“下一步”后填写最终标题、简介、话题和原创声明，最后提交一次并等待成功提示。

## 已知限制

- API 保留 500 字的异常输入上限。浏览器填标题时还会读取平台输入框的 `maxlength`，超限或填入后被截断都会停止，不自动删改标题。当前观察到长文标题上限为 64 个 UTF-16 字符，emoji 可能占两个字符。
- 当前发布预览优先支持小红书长文同步；图文笔记、视频、定时发布和多账号队列不在此入口提供。
- 长文模板与封面通过当前页面的 `.template-card-new` / `.cover-item` 文案定位；平台调整文案或 DOM 时需要同步更新选择器。
- 模板、封面摘要和勾选项无法准确设置时会停止，不再静默跳过。平台禁用的“字数和时长”若与用户要求不一致，需要调整配置。
- 封面开关通过隐藏 input 所属的 `.d-switch` 切换；封面摘要通过 `.editable-overlay` 中的文本框编辑，关闭遮罩并回读摘要后才继续。
- 话题在最终页富文本末尾输入，只选择浮层中的同名现有话题，并检查 `a.tiptap-topic` 的 `data-topic` 名称与 ID。不自动创建新话题，无法确认关联时会停止。
- 开启原创声明时，会完成“原创声明须知”确认弹窗后再提交。
- 小红书出现验证码、滑块或登录态失效时不会自动绕过；需要人工完成验证并重新绑定 Cookie。
- 使用 Playwright 实际浏览器的默认 User-Agent，避免伪装成固定的旧版 Chrome。浏览器参数不能保证平台不触发验证。
- 发布页 DOM 变化可能导致选择器失效。接口会保留失败记录，便于排查和更新选择器。
- 自动流程只点击一次发布，并等待最多 60 秒的明确“发布成功”提示。“已发布”标签或进入首页、管理页不算成功。结果不明仍沿用现有失败记录，错误信息会提示先到平台核对；不要直接再次发起发布。
- 当前 closed Shadow DOM 发布按钮保留已观察布局的坐标适配，并检查宿主状态与遮挡。平台改变内部按钮排列后仍需更新适配。
- 本地需要观察 Playwright 页面时，可设置 `XIAOHONGSHU_HEADLESS=false`；部署环境默认使用无头模式，失败后会正常关闭浏览器并释放发布锁。
- AI 只生成标题、摘要与话题建议；地点、可见范围和定时发布保持小红书平台当前默认值，由用户在平台侧按需调整。

## 回归检查

```bash
cd web
node --import tsx --test scripts/test-xiaohongshu-publishing.ts
pnpm verify
pnpm smoke
```

浏览器回归使用本地 HTML 和真实 Chromium，覆盖阶段顺序、隐藏副本、标题截断、独立勾选、简介与话题、引导弹窗和单次提交。测试不连接小红书、不写入账号数据、不发布文章。真实平台验收应先停在提交前；实际发布需单独授权。

2026-09-19 经用户授权，使用当前登录的 Chrome 会话，通过 Playwriter 调用项目内的发布函数完成了真实测试：长文排版、无图封面、关闭作者展示、封面摘要、现有话题关联、原创声明确认、单次提交均已通过。平台显示“发布成功”，笔记进入“审核中”，随后删除成功；刷新后测试稿不存在，笔记总数恢复，草稿数保持不变。

该实测覆盖当前登录会话中的发布操作。服务端重新启动无头浏览器并注入 Cookie 的登录流程未在这次实测中覆盖。
