# 小红书图文发布

## 当前能力

- 在“用户页”绑定小红书创作服务平台的 Cookie JSON。
- 在每篇文章的“发布预览”页切换到“小红书长文”，直接同步当前文章标题与正文。
- 在预览页选择小红书长文模板、封面类型与封面信息展示项；可让 AI 生成下一步需要的发布标题、摘要和话题，确认后再一键同步并发布。
- 服务端以 Playwright 操作小红书创作服务平台真实的“写长文”入口与后续发布页。
- 每次请求写入 SQLite 发布记录，保留发布时间、图片数量、状态、结果链接或失败原因。

## 凭据与数据边界

- Cookie 仅保存在当前浏览器的 `localStorage`，不会写入 SQLite、日志或项目文件。
- 发布接口只在当前请求内把 Cookie 注入 Playwright 浏览器上下文，任务结束即关闭上下文。
- 图片先上传到项目既有的本地素材目录；发布记录只保存图片数量，不保存 Cookie。

## 操作方式

1. 在浏览器登录 `https://creator.xiaohongshu.com`。
2. 用 Cookie-Editor 等浏览器工具导出当前站点的 Cookie JSON。
3. 打开“用户页”，在“小红书”卡片粘贴并绑定 Cookie。
4. 打开任意文章的“发布预览”，切换到 **小红书长文**。
5. 当前文章的标题与正文会自动同步；可填写封面摘要，并选择模板、封面类型和封面信息。
6. 点击“AI 生成发布信息”，生成并允许编辑最终发布标题（最多 20 字）、封面摘要和 3–5 个话题。
7. 点击“一键发布长文”。系统会填入卡片式长文编辑器、等待自动保存、点击“下一步”，在最终发布页填写标题、话题和原创声明，再完成发布。

## 已知限制

- 当前发布预览优先支持小红书长文同步；图文笔记、视频、定时发布和多账号队列不在此入口提供。
- 长文模板与封面通过当前页面的 `.template-card-new` / `.cover-item` 文案定位；平台调整文案或 DOM 时需要同步更新选择器。
- 小红书出现验证码、滑块或登录态失效时不会自动绕过；需要人工完成验证并重新绑定 Cookie。
- 发布页 DOM 变化可能导致选择器失效。接口会保留失败记录，便于排查和更新选择器。
- AI 只生成标题、摘要与话题建议；地点、可见范围和定时发布保持小红书平台当前默认值，由用户在平台侧按需调整。
