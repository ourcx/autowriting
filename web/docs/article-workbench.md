# 文章工作台与发布耗时指标

文章编辑器的主流程统一为“任务 → 素材 → 写作 → 审核 → 发布”。今日头条、小红书、封面和图片库属于平台与素材辅助能力，不参与公众号主流程完成度。公众号样式预览、封面选择和草稿推送直接在编辑器的发布阶段完成；原独立预览页继续保留，供需要更大画布时使用。

每篇服务端文章在正文同目录保存 `article_workflow*.json`，不修改 SQLite。文件只记录流程时间，不保存正文或凭据：

- `createdAt`：已有文章取现有文件最早创建时间，新文章取第一次打开时间。
- `firstGeneratedAt`：首次形成有效正文。
- `lastReviewedAt`：最近一次 AI 深度审核完成时间。
- `wechatDraftOpenedAt`：首次进入公众号发布阶段。
- `wechatDraftAt`：微信草稿接口成功后由工作台记录。

核心指标为 `wechatDraftAt - createdAt` 的中位数。上线前记录至少一周基线，上线后按相同账号与文章类型观察两周；目标降低 30%。护栏指标为微信草稿推送成功率、文章最终发布率和生成后正文保留比例，避免单纯缩短耗时造成质量下降。

本地文章的工作流时间保存在浏览器 `localStorage`，迁移到服务端后按服务端文章重新记录。历史文章没有工作流文件时会根据任务、素材、正文与已有文件时间推导当前阶段，不改写正文。

本地规范核查会读取本篇任务中的目标字数、第一人称要求、`不要提到/出现/使用` 的词语和 emoji 限制。任务要求优先于默认写作偏好。

## P1：平台版本与效果反馈

公众号正文作为事实与观点母稿，今日头条版本单独保存。工作台展示平台版本相对母稿的字数变化、原样保留段落比例，避免三个编辑框各自发展成互相矛盾的文章。小红书当前继续复用母稿正文，只维护平台标题和发布信息。

“历史表现参考”读取当前用户在文章评分页录入的阅读、点赞、转发和综合评分，展示高表现文章、常见标题字数、正文长度和平均分最佳平台。原有生成链路会注入高、低表现示例；工作流文件新增本次使用的提示词、参考文章和最终公众号模板，后续评分可回看具体生产上下文。旧文章缺少这些字段时保持为空，不推断不存在的归因。

## P2：账号档案与事实来源

用户页新增账号写作档案，按用户隔离保存受众、立场、语气、禁用表达、常用结构、默认平台和视觉倾向。服务端在生成公众号和今日头条版本时自动注入档案，并明确单篇任务要求优先。生成弹窗会使用档案中的公众号、今日头条默认选择；小红书仍在发布阶段处理。

审核页从素材中提取来源链接，并检查正文数字、日期是否能在本篇素材中找到相同证据。检查结果只提示“可回查”或“待核对”，不把字符串匹配当作事实真实性结论。来源过旧、来源质量和 AI 推断仍需要人工判断。

验证命令：

```bash
pnpm --dir web smoke
pnpm --dir web test:production
pnpm --dir web dev --host 127.0.0.1
node web/scripts/test-article-workbench.mjs
```

浏览器回归使用内存接口，不写用户文章，不调用真实模型或公众号。真实微信草稿推送仍需在目标账号验证。

## 首页到发布的路径

首页按现有生产阶段提供“继续处理”，优先展示待推送、待审核文章；文章列表支持标题或日期搜索、进度筛选，以及公众号、今日头条、小红书发布工作台直达入口。耗时统计独立加载，失败或变慢不会阻断文章列表。导航按创作工具、设计、账户与配置分组，所有入口直接可见，不放入折叠菜单。

首页页头、侧栏和列表统一白底，移除大面积拼色。“继续处理”使用单行布局。桌面导航与筛选为 32px，发布平台切换为 36px，以细下划线表示选中状态；颜色仅用于少量图标和状态点。浏览器回归额外检查入口可见性、背景一致性和 tab 高度。

编辑器首次打开按 `currentStage` 进入对应步骤，随后以 `?tab=` 保留当前工作区。发布平台使用 `?tab=publish&platform=wechat|toutiao|xiaohongshu`；这些参数只影响页面选择，不代表审核或发布完成。非法参数回退到有效步骤及公众号平台。

从编辑区进入发布区、打开独立预览前先保存；保存失败留在原页面。发布区复用现有 `WeChatRenderer`，三平台直接切换，不新增发布接口。头条没有独立正文时显示空状态，不以公众号正文冒充头条版本。小红书使用独立标题和公众号母稿。独立预览返回时保留平台。

“已推送微信草稿”不等于已群发；群发仍在微信草稿页确认。头条和小红书沿用各自账号绑定、发布确认和执行流程。没有新增生产状态、数据库字段或平台耗时指标，尚不能根据本轮变更宣称端到端耗时降低了多少。

页面按需加载后，本次构建首页入口 JS 由约 2.20 MB 降至 279 KB，gzip 由约 713 KB 降至 94 KB。编辑器、画布和统计页面进入时再下载。该结果是产物大小比较，不是用户真实网络环境下的耗时测量；Markdown 渲染共享包仍较大。
