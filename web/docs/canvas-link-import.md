# 秀米公开分享链接预览（已下线）

当前画布使用内置固定模板，已移除 AI 排版、秀米链接导入、设计参考导入，以及对应的页面组件。模板通过 `compileCanvasDesignSystem` 本地编译；保留现有内容编辑、撤销重做、保存和导出。旧版后端接口暂保留兼容，当前页面不会调用。Markdown 样式管理和文章正文写作不在本次修改范围。

当前浏览器回归覆盖模板应用、文章隔离、编辑持久化和导出，并断言全过程没有 AI 排版请求。回滚可 revert 此次下线提交，不清理用户已保存排版。

以下记录原实现，供维护参考。

历史入口（当前不可用）：画布 → 主题与模板 → 从秀米公开分享链接生成。选择当前文章、粘贴 HTTPS `board/v5` 分享链接，点击生成模板预览。预览不会覆盖画布；应用后进入现有编辑器和撤销历史，取消则丢弃候选稿。

后端只读取公开分享页及页面指向的秀米公开排版 JSON，不登录，不读取用户 Cookie。白名单限定单字母分享域名（xiumi.us/xiumius.cn）和 sd 数据域名；重定向逐跳检查，DNS 排除内网并固定连接 IP，限制大小、时长和并发，接口复用画布鉴权。没有数据库或持久化状态变更。

从结构化 style 与渲染缓存的内联样式提取允许的配色、尺寸和布局属性，删除原文、图片地址、脚本和事件。参考数据交给既有 AI 设计参考流程，为当前文章生成安全 DSL。不能保证逐像素还原；复杂插画、动画和特殊交互会简化。不支持编辑器地址、需登录页面、H5 stage 页面或临时预览。

验证：公开的秀米分享教程链接读取成功；URL 白名单/样式过滤测试通过；新增未登录拒绝和非法主机 smoke。浏览器使用模拟的读取与模型返回，验证预览不覆盖、应用和撤销；不把它当作真实模型生成成功率证明。本机无服务端 AI 密钥，真实模型部分仍需配置后验证。
