# 公众号画布：知识分享文章的阅读排版

画布复用已有的 AI 写作文章。选择正文后，可直接应用模板试排，也可让 AI 基于补充要求生成排版，再调整局部样式并复制公众号富文本。

## 本轮体验

- 默认“杂志叙事”：30px 标题、22px 章节、17px 正文，20px 两侧留白。正文与单张图片上下排列，连续图片仍可组成画廊。
- 导语与引用沿用纸面底色，用字重、字号和留白建立节奏；短引用居中，长引用保持左对齐。不使用引用框、标题竖线或自动标题下划线，正文不轮换双栏、图标和卡片。模板质量检查接受有完整文字层级的单栏长文，同时继续检查内容覆盖、分组及视觉手段。
- 三张模板缩略图由实际排版器生成。选中模板后点击“应用模板”生效，无需调用 AI；设计文件驱动仍使用 AI 入口。
- 375 / 414 / 677px 预览使用真实排版宽度，不缩放字体。阅读预览隐藏选中框和编辑面板。
- 最近 30 步排版修改支持撤销、重做；切换文章清空历史。排版沿用原本的本机自动保存方式，历史不持久化。
- 选择段落后优先显示局部样式，整篇设置收起。刷新后忽略解析得到的 undefined 局部字段，防止覆盖正文默认样式。
- 重新套模板保留行内强调。AI 请求期间切换文章，旧文章返回结果不会写入新文章。

首次打开没有本地排版记录的文章会应用默认模板；已有记录仍然保留。主动应用模板会替换布局，可撤销。本文未改变文章存储、鉴权、发布接口或数据格式。

## 验收

```bash
pnpm --dir web test:canvas
pnpm --dir web dev --host 127.0.0.1
# 另开终端执行；浏览器、身份和文章数据均为隔离测试环境。
pnpm --dir web exec node --import tsx scripts/test-canvas-studio.mjs
```

浏览器脚本要求 Vite 开发服务可访问，默认地址为 `http://127.0.0.1:5173`，可通过 `CANVAS_STUDIO_URL` 修改。截图、导出 HTML 和报告写入系统临时目录，可用 `CANVAS_TEST_OUTPUT` 指定产物目录，不写入项目运行数据。

浏览器回归覆盖模板切换、局部字号修改、撤销重做、375 / 414px 预览、横向溢出、刷新保留样式、真实剪贴板 HTML、模拟 AI SSE 返回，以及跨文章请求隔离。文章读取、身份和 AI 响应使用测试数据；它不证明真实模型生成质量或微信后台粘贴结果。微信侧兼容性仍需在目标公众号编辑器验收。

本轮未新增正文写作接口或自由拖拽模块库；正文生成继续使用现有写作入口，画布负责排版及局部样式调整。

已有本机排版记录不会被自动重写。切换到“杂志叙事”并点击“应用模板”即可采用无引用框样式，也可撤销此次替换。
