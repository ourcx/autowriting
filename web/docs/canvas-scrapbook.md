# 手绘纸笺与装饰素材

在画布的公众号排版模式选择「手绘纸笺」，点击「应用模板」即可使用，无需调用模型。AI 设计排版也可选择这一模板。旧文章的本机排版不自动替换；应用模板及插入素材均支持撤销。

本次实际打开秀米图文编辑器，对照了图片素材的插画、边框、背景分类，并结合用户提供的教师节示例实现整篇纸张风格。参考地址：https://xiumi.us/studio/v5 。素材为本项目通过 imagegen 新生成的原创水彩图，不是从秀米下载的素材。

## 能力与数据

- 奶油底、粉蓝标题签、水彩彩旗开篇、活页纸章节、夹板照片、连续照片错位排列；文字保持可编辑。
- 「照片与插画库」复用已有 `/api/images` 只读接口，按名称筛选并插入照片；不改变原文图片。照片保存在可选 `asset.libraryImage`，只接受 HTTPS 或已有上传图片路径，不接受脚本协议。原有图库为空时展示空态，不假装已接入外部搜索。
- 「装饰素材库」内置彩旗与纸飞机、活页环、心形夹板三个素材，可插在选中内容之后；未选中时追加到结尾。右侧可更换素材并调整尺寸、间距、对齐。
- DSL 向后兼容的可选字段：`theme.publicationStyle: "scrapbook"`、`section.frame: "notebook" | "photo" | "collage"`、`asset.materialId`。不认识的素材 ID 丢弃；内置素材通过白名单映射静态资源，不能提供任意 URL。
- 成套手绘配色不再经过单主色清洗；原有模板保持其配色策略。全篇主题策略放在 shared/canvasScrapbook.ts，正文源和内容顺序不变。
- 资源在 public/canvas-materials，刷新不重新生图。导出时按显示尺寸的两倍内嵌 PNG，保留透明度，避免本机资源链接失效；未加载的素材会阻止复制并显示错误。

## 验收边界

`pnpm --dir web test:canvas` 覆盖五套模板、DSL 回填和素材白名单；`scripts/test-canvas-studio.mjs` 使用隔离文章/身份/AI 响应，覆盖真实页面上的模板应用、装饰插入、已有图库照片筛选插入、撤销、刷新、375/414/677px 阅读、复制 HTML 及独立导出页。手动浏览器预览额外检查夹板和错位图片布局，照片为明确标注的测试示意图。

尚未验证真实模型出图、微信后台实际粘贴和发布效果。素材库当前是三件首批原创装饰，未接外部照片搜索服务。没有修改数据库、权限、公众号发布接口，也没有部署或推送。
