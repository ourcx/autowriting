# 手绘纸笺与装饰素材

在画布的公众号排版模式选择「手绘纸笺」，点击「应用模板」即可使用，无需调用模型。AI 设计排版也可选择这一模板。旧文章的本机排版不自动替换；应用模板及插入素材均支持撤销。

本次实际打开秀米图文编辑器，对照了图片素材的插画、边框、背景分类，并结合用户提供的教师节示例实现整篇纸张风格。参考地址：https://xiumi.us/studio/v5 。素材为本项目通过 imagegen 新生成的原创水彩图，不是从秀米下载的素材。

## 能力与数据

- 奶油底、粉蓝标题签、水彩彩旗开篇、活页纸章节、夹板照片、连续照片错位排列；文字保持可编辑。
- 「照片与插画库」复用已有 `/api/images` 只读接口，按名称筛选并插入照片；不改变原文图片。照片保存在可选 `asset.libraryImage`，只接受 HTTPS 或已有上传图片路径，不接受脚本协议。原有图库为空时展示空态，不假装已接入外部搜索。
- 「装饰素材库」内置彩旗与纸飞机、活页环、心形夹板及矢量彩旗、活页环、纸飞机、枝叶共七个素材，可插在选中内容之后；未选中时追加到结尾。右侧可更换素材并调整尺寸、间距、对齐。
- DSL 向后兼容的可选字段：`theme.publicationStyle: "scrapbook"`、`section.frame: "notebook" | "photo" | "collage" | "letter" | "ticket"`、`asset.materialId`。不认识的素材 ID 丢弃；内置素材通过白名单映射静态资源，不能提供任意 URL。
- 成套手绘配色不再经过单主色清洗；原有模板保持其配色策略。全篇主题策略放在 shared/canvasScrapbook.ts，正文源和内容顺序不变。
- 资源在 public/canvas-materials，刷新不重新生图。导出时按显示尺寸的两倍内嵌 PNG，保留透明度，避免本机资源链接失效；未加载的素材会阻止复制并显示错误。

## 验收边界

`pnpm --dir web test:canvas` 覆盖五套模板、DSL 回填和素材白名单；`scripts/test-canvas-studio.mjs` 使用隔离文章/身份/AI 响应，覆盖真实页面上的模板应用、装饰插入、已有图库照片筛选插入、撤销、刷新、375/414/677px 阅读、复制 HTML 及独立导出页。手动浏览器预览额外检查夹板和错位图片布局，照片为明确标注的测试示意图。

尚未验证真实模型出图、微信后台实际粘贴和发布效果。素材库当前有三件水彩装饰和四件原创 SVG 装饰，未接外部照片搜索服务。没有修改数据库、权限、公众号发布接口，也没有部署或推送。

## AI 布局和 CSS/SVG 组合

生成终检先补齐所选主题的颜色、字号与留白，再保留对应章节的 AI 布局和组件决策。内容缺失或重复仍由模板兜底，主动「应用模板」继续确定性重排。

`section.frame` 与 `section.layout` 独立：如 `letter + timeline`、`ticket + steps`、`photo + media-text`。letter/ticket 使用内联 CSS，notebook/photo 沿用水彩装饰；collage 在全图片章节使用错位布局。itemStyles 控制标题签与正文；asset 通过 anchorSourceId/placement 在章节前后插入素材。当前不支持任意深度嵌套或自由定位。

生成提示按内容选组件：校园用活页/纸飞机，节庆用彩旗/票券，自然旅行用枝叶/照片，书信用信纸，严肃技术文章优先无纸框。AI 输出组件 ID 与既有 DSL，不执行模型生成的 HTML 或脚本。

内置 SVG 以图片加载，复制时转为透明 PNG 内嵌。自由 SVG 路径和图标在 HTML 构建阶段保留完整矢量图，复制到剪贴板时转为 PNG，不再降级为线条或删除父容器；交互 SVG 保持原流程。微信后台的实际粘贴仍待实测。

新增回归覆盖 AI 组合保留、错误内容兜底、素材白名单、浏览器组合修改/刷新/手机宽度，以及自由 SVG 与相邻文字保留。AI 响应仍用测试夹具，不能据此推断真实模型成功率。

本轮验证：五模板及新增组合保留测试通过；浏览器验证信纸时间线、SVG 插入、刷新、375/414/677px 无溢出、复制 PNG 与相邻正文保留，并检查导出时间线正文列大于行宽 70%。修复导出器对未指定宽度单元格强制设置 50% 的问题。定向 lint、改动类型检查、arch 和 build 通过；verify 仍被未修改文件中的 31 个 lint 错误阻断，全量 TypeScript 仍仅有两个既有未使用 React 导入错误。隔离 smoke 为 24 pass / 0 fail。

## 生成与编辑空间回归修复

分段生成仅返回紧凑结构，必须经过模板补齐字号、留白、标题层级和统一配色。终检保留可对应到章节的 layout/frame/列比例等布局决策，主题样式由所选模板补齐，不再直接返回解析默认值。分段提示同步支持 frame 和白名单素材；它与完整生成提示使用相同组件集合。

模板、设计参考、素材收进同一行折叠菜单；展开为可滚动浮层，选择模板后关闭，默认不占用正文空间。当前主色展示在工具栏。新增 1366×768 下编辑区顶部小于 280px、可用高度大于 450px 的浏览器断言，以及最小 AI 输出的配色与标题样式回归。测试仍使用模拟模型返回；本机环境未配置服务端模型密钥，未验证真实模型调用。
