# 公众号画布模板、章节组件与素材

画布提供 19 套固定整篇模板、10 种章节组件和 31 款内置素材。所有排版都在本地通过确定性设计系统完成，不依赖 AI 请求。

## 使用流程

1. 在“主题与模板”选择整篇模板，点击“应用模板”。模板会同时应用主题色、字体、章节布局，以及开篇、章节和结尾素材。
2. 在正文或左侧文章结构中选中一个章节，打开“章节组件”，一键替换为留白正文、侧线章节、柔色卡片、票券章节、信纸章节、编号步骤、时间线、双栏摘要、图文故事或杂志导语。
3. 打开“素材库”，使用关键词和分类筛选素材。手动插入的素材锚定在当前章节之后，可以移动、删除并随文章保存。
4. 使用 375、414 和 677px 预览检查文章，再复制富文本或推送公众号。

## 数据与兼容规则

- 模板素材以 `template:` 标记。切换整篇模板时替换这些素材，人工插入的素材不会删除。
- 每套模板最多自动组合开篇、首个章节和结尾三个素材，避免长文重复装饰。
- 章节组件只修改选中章节的表现，不改变 `sourceIds`、正文内容或顺序，并进入现有撤销历史。
- 图文组件遇到没有图片的章节时回退为大字重点布局，避免空白图片栏。
- 保存解析最多保留 12 个素材，为模板素材和人工编排共同留出空间。
- 内置素材仍通过白名单 ID 引用，公众号复制时转成可携带的图片数据。

## 维护入口

- 整篇模板：`shared/canvasDesignTemplates.ts`
- 模板编译：`shared/canvasDesignSystem.ts`
- 章节组件：`shared/canvasSectionPresets.ts`
- 素材目录：`shared/canvasMaterialLibrary.ts`
- 页面入口：`src/pages/CanvasStudio/`

运行 `pnpm --dir web test:canvas` 验证模板数量、内容覆盖、模板素材、章节组件和保存解析；启动前端后在 `web` 目录运行 `node --import tsx scripts/test-canvas-studio.mjs` 验证真实交互、撤销、刷新、导出和各宽度无溢出。
