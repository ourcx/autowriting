# 秀米排版接入

`/canvas` 默认使用秀米官方插件。旧排版和自由画板分别保留在 `?mode=blocks`、`?mode=svg`，原有本机数据继续保留。

1. 选择文章，点击「复制正文到秀米」，在秀米中粘贴、排版。
2. 点击秀米顶部对勾，排版 HTML 回传平台；图片转存成功后，按文章 ID 保存到本机。
3. 预览、复制已保存排版，或推送到微信公众号草稿箱。推送仍需公众号配置及文章封面。

秀米插件只提供回传接口，不自动把平台正文或已保存 HTML 写回秀米。继续编辑请在秀米「我的图文」打开原稿。HTTPS、秀米账号登录及第三方 Cookie 由浏览器处理；嵌入登录或回传不可用时，可在新窗口排版，再复制粘贴回来。

接入遵循官方 `XIUMI:3rdEditor:Connect` 协议，只接收当前编辑器窗口、`https://xiumi.us` 来源的 HTML。HTML 经现有 DOMPurify 清理后展示在禁用脚本的独立预览中，保留内联排版，不经过旧 DSL 或块样式编译。

秀米图片通过鉴权接口下载，限定秀米 HTTPS 域名、公开地址、20MB、15 秒超时、禁止重定向，并校验图片格式。存储复用图片上传接口；普通图片、内联 CSS 背景和 SVG 图片引用一并转存，转存失败时不覆盖上一次完整排版。推送时本地图片继续转存到微信。

## 默认模板

画布顶部提供全部 42 套内置 MD 模板，初始选中「青柠小报」。选择模板后可预览；「用正文生成排版」会按当前文章正文生成并保存，「复制模板正文到秀米」可带样式进入秀米继续编辑。选模板和预览不会覆盖已保存排版。

旧版画布另增加 12 套可编辑主题：青柠小报、橘子周末、莓果相册、薄荷笔记本、黄油烘焙社、航空旅行信、紫藤游园会、蜜桃拼贴簿、钴蓝独立刊、复古放映厅、樱花诗笺、夏日俱乐部。复用现有信纸、票券、相框、底纹和素材，在「旧版排版 → 主题与模板」选择后应用。
