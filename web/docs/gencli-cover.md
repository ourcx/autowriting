# 用本机 Gen CLI 生成封面

打开「AI 配置 → 封面 → Gen CLI」，下载本机客户端。已安装 gencli 的电脑在下载目录运行：

```sh
python3 dashy-gencli.py
```

将终端中本次启动的配对码填入页面，点击「测试本机连接」并保存。浏览器如果询问本机网络权限，允许当前 Dashy 站点访问本机。可在文章封面工具选择「Gen CLI」生成。客户端使用 gencli 的 GPT Image 2 路由和现有登录，默认请求 16:9 封面。客户端尽量保持运行，重启后需要重新填入配对码。

封面提示词从浏览器传给本机客户端，随后由 gencli 调用模型服务。Dashy 线上服务不参与生图或自动接收图片。生成后可本地预览、下载，也可通过已有按钮手动保存图片库或发布。选 Gen CLI 后，当前浏览器优先使用本机生图，部署服务保留原先的封面服务。

客户端只监听 127.0.0.1:18472，只接受指定站点与本次生成的配对码。发起生图时只提交提示词，本机端使用固定命令和受限的临时目录，不接收页面传入的命令参数或输出路径。每次只处理一个生成请求，浏览器配对码与 gencli 登录状态各自留在本机。
