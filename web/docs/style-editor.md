# Markdown 样式管理

`/styles` 新增青苔手记、奶油来信、蓝调专栏、玫瑰刊物四套内置模板。与正文渲染器共享前端模板列表，无数据库结构变化。默认展示连续短文，组件预览用于检查代码、表格等元素。

AI 生成使用 apiHelpers 的登录请求。没有本地密钥时不发送默认空配置，保留服务端模型配置；配置了本地密钥则使用用户配置。返回空样式会提示重试。生成结果直接显示在右侧，取消可恢复原样。

内置模板的 AI 结果另存为自定义模板；自定义模板应用后需要保存。保存和删除接口失败会保留编辑内容并显示错误，不再把 HTTP 失败当作成功。读取失败仍兼容旧的本地模板缓存。

验证：启动前端后在 web 目录执行 `node scripts/test-style-editor.mjs`。接口与 AI 使用内存模拟，不写真实数据；覆盖四套模板、凭证、空配置、预览取消、另存及刷新、保存失败、空结果。真实模型响应和微信发布效果需在目标环境进一步验证。

回滚：revert 本功能提交；不删除已保存的用户模板。

画布页与样式页的主要操作共用 `components/Button`：统一主次、危险、禁用和键盘焦点样式，业务请求仍由页面处理。模板选择保留真实排版缩略图，预览外框不添加额外主题色装饰，以便准确判断文章样式。
