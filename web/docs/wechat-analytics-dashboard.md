# 微信数据看板

数据看板通过本机 Chrome DevTools Protocol 读取已登录的微信公众平台页面。登录 Cookie 留在独立浏览器配置目录，不进入应用数据库、接口响应或日志。

## 启动

先启动专用浏览器：

```bash
pnpm --dir web wechat:analytics:browser
```

首次使用时扫码登录公众号，进入“数据分析 > 内容分析”，选择需要观察的日期范围。保持该页面打开，再启动应用：

```bash
pnpm --dir web start
```

打开“数据看板”，点击“立即同步”。开启“定时刷新”后，服务端会按设置的间隔重读当前内容分析页。应用默认连接 `http://127.0.0.1:9222`；如需改端口，可设置 `WECHAT_ANALYTICS_CDP_URL`，但仅允许本机地址。

## 数据口径

- 采集接口按 `offset/count` 翻页，直到微信返回 `next_offset=0`，最多保存 500 篇。
- 阅读指标是所选统计期内的阅读人数，不等于发布后的累计阅读。
- 同一个人阅读多篇文章时会分别计入各篇，不能把文章阅读人数相加当作账号去重人数。
- “高关注”和“低关注”按同一快照内的分位划分，只表示相对位置，不代表写作质量。
- 作者偏好来自编辑器中明确保存的“写作取舍”，不会从高阅读文章的句式自动推断。

## 故障恢复

看板会保存最后一次成功快照、最后尝试时间和错误摘要。同步失败时继续展示旧快照，并明确标出旧数据时间。登录过期后，在专用浏览器重新登录即可；不需要把 Cookie 复制到应用中。
