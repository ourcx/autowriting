# 文章审校清单

在发布前，必须逐项检查以下内容。

## ✅ 内容层面

### 标题
- [ ] 是否吸引眼球？（测试：你自己会点开吗？）
- [ ] 是否准确表达文章主题？
- [ ] 字数是否在 10-20 字之间？
- [ ] 是否避免了标题党（过度夸张）？

### 开场
- [ ] 是否直接切入主题？（删除"大家好"之类的开场白）
- [ ] 是否抛出了具体问题或场景？
- [ ] 前 100 字能否吸引读者继续读？

### 主体内容
- [ ] 是否有至少 1 个真实数据或案例？
- [ ] 是否有可直接执行的操作步骤？
- [ ] 是否分享了真实的坑和解决方案？
- [ ] 每个观点是否有支撑（数据、案例、逻辑）？

### 结尾
- [ ] 是否有明确的行动建议？
- [ ] 是否有互动引导（点赞、在看、转发）？
- [ ] 是否避免了空泛的总结句？

## ✅ 语言层面

### AI 套话检查
逐行扫描，删除以下表达：

#### 空洞开场
- [ ] "在当今这个快速发展的时代"
- [ ] "随着科技的不断进步"
- [ ] "大家好，今天我要分享"

#### 空泛总结
- [ ] "总而言之/总的来说/综上所述"
- [ ] "希望本文对你有所帮助"
- [ ] "让我们一起拥抱未来"

#### 陈词滥调
- [ ] "打开了新世界的大门"
- [ ] "不得不说/不得不提"
- [ ] "值得一提的是"
- [ ] "说实话/老实说"（除非真的在对比）

#### 过度修饰
- [ ] "极大地/显著地/大幅度地" → 用具体数据
- [ ] "非常/十分/相当" → 删除或具体化
- [ ] "深刻的/深度的/全面的" → 用具体描述

#### 机器人式过渡
- [ ] "接下来，让我们来看看"
- [ ] "首先...其次...最后"（可用数字代替）
- [ ] "下面我将详细介绍"

### 人称和语气
- [ ] 是否全文使用「我」而非「我们」？
- [ ] 是否像朋友聊天一样，而非官方发言？
- [ ] 是否避免了教科书式的表达？

### 具体性检查
- [ ] 模糊描述是否改为具体数据？
  - ❌ "大幅提升效率" → ✅ "节省 2 小时"
  - ❌ "很多人" → ✅ "87% 的用户"
- [ ] 抽象概念是否有具体例子？
  - ❌ "提升用户体验" → ✅ "页面加载从 3 秒降到 1 秒"

## ✅ 格式层面

### 标题格式
- [ ] H1 是否只有 1 个？
- [ ] H2 是否都加了 emoji？
- [ ] H3 是否不加 emoji？
- [ ] 标题层级是否清晰（不跳级）？

### 标点符号
- [ ] 中文引号是否使用「」和『』？
- [ ] 是否避免使用 "" 双引号？
- [ ] 破折号是否使用 ——？
- [ ] 省略号是否使用 ……？
- [ ] 感叹号是否适度（每段最多 1 个）？

### 段落结构
- [ ] 每段是否在 3-5 行？
- [ ] 是否避免了超过 150 字的段落？
- [ ] 段落间是否空了一行？
- [ ] 是否善用了列表和编号？

### 代码格式
- [ ] 代码块是否标注了语言？（```bash 而非 ```）
- [ ] 命令行是否加了注释？
- [ ] 代码是否有必要的说明文字？

### 图片
- [ ] 是否有封面图？
- [ ] 封面比例是否为 2.35:1？
- [ ] 正文配图是否清晰？
- [ ] 每张图是否有说明文字？

## ✅ 质量层面

### 真实性
- [ ] 数据是否真实可靠？
- [ ] 案例是否真实发生过？
- [ ] 方法是否亲自验证过？

### 实用性
- [ ] 读者能否立即行动？
- [ ] 操作步骤是否完整？
- [ ] 是否考虑了常见问题？

### 独特性
- [ ] 是否有个人观点或判断？
- [ ] 是否分享了独特经历？
- [ ] 是否与网上千篇一律的文章不同？

## ✅ SEO 检查

### 关键词
- [ ] 标题是否包含核心关键词？
- [ ] 关键词是否自然出现 3-5 次？
- [ ] 是否避免了关键词堆砌？

### 可读性
- [ ] 是否有小标题便于扫读？
- [ ] 重点内容是否突出（加粗、列表）？
- [ ] 长句是否拆分为短句？

## ✅ 法律和伦理

### 版权
- [ ] 图片是否有版权或自己生成？
- [ ] 引用内容是否标注来源？
- [ ] 是否避免了抄袭？

### 敏感信息
- [ ] 是否包含公司内部数据？
- [ ] 是否包含他人隐私信息？
- [ ] API Key 等敏感信息是否已脱敏？

## 📊 评分标准

每个检查项 1 分，总分 50+：

- **45-50 分**：优秀，可以发布
- **40-44 分**：良好，稍作调整
- **35-39 分**：及格，需要修改
- **< 35 分**：不及格，重写

## 🎯 快速审校流程

1. **通读全文**（5 分钟）
   - 整体感觉是否流畅？
   - 是否像人写的？

2. **AI 套话扫描**（5 分钟）
   - 用 Ctrl+F 搜索禁用词
   - 逐个删除或替换

3. **格式检查**（3 分钟）
   - H2 是否加 emoji
   - 引号是否正确
   - 代码块是否规范

4. **数据核实**（5 分钟）
   - 检查所有数字
   - 验证技术细节

5. **最终通读**（5 分钟）
   - 从读者角度审视
   - 是否愿意转发？

**总耗时**：约 20-25 分钟

---

**提醒**：审校是保证质量的关键，不要为了快而跳过！
